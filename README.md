# Edullecta — React Website

A responsive React/Vite marketing website for **Edullecta**, based on the supplied *Edullecta Student Development Brochure*.

## Included
- Responsive landing page with mobile navigation
- Edullecta brand treatment and brochure hero visual
- About / mission section
- All 9 core programmes represented in the brochure
- Special programmes & events section
- Edullecta Future Fest section
- Student-development approach / pillars
- Contact / enquiry form demo
- Programme detail modal interactions
- Responsive styling for desktop, tablet and mobile

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite local URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

The supplied brochure image is at `public/assets/brochure.png`.

> The contact form is intentionally front-end only. Connect it to your email service, CRM, Formspree, Supabase, or backend API before production.
